# UNI-MATE Backend

API cho nền tảng kết nối sinh viên UNI-MATE (EXE201).

## Công nghệ
Node.js · Express · MongoDB Atlas · Mongoose · JWT

## Chạy local
```bash
npm install
npm run dev
```
Tạo file `.env` theo mẫu `.env.example`.
